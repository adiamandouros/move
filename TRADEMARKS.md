# The Wayhop name and logo

The code's license (the GNU AGPL, see [LICENSE](LICENSE)) covers the code. It
doesn't cover the name "Wayhop", the Wayhop logo and icons in `public/icon/`,
or the wayhop.gr domain. They identify the official site, so people know
which one they're using.

You're welcome to:

- run, change and share the code under the AGPL, including on your own site;
- say that your project is based on Wayhop, or links to it.

If you run a copy or a fork for other people, please:

- give it a different name and logo, and don't use "Wayhop" in its domain;
- don't make it look like the official site, or like it's endorsed by it.

For anything else, such as a partnership or using the name in an article
or a talk in a way this doesn't cover, open an issue or use the contact page
at <https://wayhop.gr/contact>.
